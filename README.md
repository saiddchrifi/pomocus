## Live Demo
saiddchrifi.github.io/pomocus/

## Features

- 25-minute focus sessions
- 5-minute short breaks
- 15-minute long breaks
- Automatic session switching
- Start / Pause / Reset controls
- Session progress tracking
- Responsive design (mobile + desktop)
- Clean and minimal UI

---

## How It Works

1. Click **Start** to begin a focus session.
2. When the timer reaches 00:00, it automatically switches to a break.
3. After 4 completed focus sessions, a long break starts.
4. You can pause or reset at any time.
